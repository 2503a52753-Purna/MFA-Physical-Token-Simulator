How This Hardware Token Works in 3 Simple Steps

Just like a banking security token or RSA SecurID, this system provides unbreakable Multi-Factor Authentication:

1
Press Hardware Button

Press the push-button on your physical ESP32 token. It calculates a synchronized 6-digit OTP code on the OLED screen that is valid for 30 seconds.

2
Enter Code into Login

The user types this temporary 6-digit code into the Enterprise Cloud Login Portal (or clicks the convenient Auto-Fill button).

3
AWS Cloud Verifies

AWS Lambda checks the cryptographic HMAC hash, verifies time drift tolerance, saves the consumed step to prevent reuse, and grants secure access!
